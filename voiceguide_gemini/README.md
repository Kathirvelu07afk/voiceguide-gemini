# VoiceGuide — Flask + Gemini Voice Assistant

A simple chatbot website built with:

- **Flask + Python** for the backend
- **Google Gemini API** for the conversation brain
- **HTML/CSS/JavaScript** for the UI
- **Browser SpeechRecognition** for microphone input
- **Browser SpeechSynthesis** for text-to-speech

There is no task-specific chatbot logic. The assistant response is generated by Gemini.

## 1. Create a virtual environment

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, you can skip activation and run:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 2. Add your Gemini API key

Copy `.env.example` to `.env`:

```powershell
Copy-Item .env.example .env
```

Open `.env` and replace:

```text
GEMINI_API_KEY=PASTE_YOUR_KEY_HERE
```

The key stays server-side in Flask and is never sent to the browser.

## 3. Start Flask

```powershell
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```

You do **not** need `uvicorn`. This project is Flask-based.

## Voice behavior

1. Click the microphone.
2. The UI enters **Preparing mic…** and then **Listening…**.
3. Speak naturally. Interim speech appears in the listening bar.
4. After a final transcript is received, the text is added to the chat.
5. Flask sends the conversation to Gemini.
6. Gemini's reply appears in the chat.
7. Text-to-speech automatically reads the reply when the speaker button is enabled.

### Browser notes

For microphone input, use a browser with the Web Speech API enabled (Chrome/Edge are common choices). `localhost`/`127.0.0.1` is appropriate for local testing. The browser will ask for microphone permission.

### Changing the Gemini model

Set `GEMINI_MODEL` in `.env` to an available model in your Google AI Studio/API account.
